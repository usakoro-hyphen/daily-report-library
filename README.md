# 📸 写真文字読み取りアプリ

MacOSで動作する写真から文字を読み取ってテキストファイルに保存するアプリケーションです。

## 🌟 機能

- 📁 画像ファイルの選択（PNG、JPEG、GIF、BMP、TIFF対応）
- 🔍 OCR（光学文字認識）による印刷文字の自動読み取り
- ✍️ **手書き文字認識機能**（NEW！）
- 🌐 日本語と英語の文字認識に対応
- 💾 読み取った文字をテキストファイルとして保存
- 🖼️ 選択した画像のプレビュー表示
- 📝 読み取った文字の編集機能

## 📋 必要な環境

- macOS 10.14以降
- Python 3.7以降
- Tesseract OCRエンジン

## 🛠️ インストール手順

### 1. Tesseract OCRのインストール

まず、Homebrewを使ってTesseract OCRエンジンをインストールします：

```bash
# Homebrewがインストールされていない場合は、まずHomebrewをインストール
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Tesseract OCRと日本語言語パックをインストール
brew install tesseract tesseract-lang
```

### 2. Pythonライブラリのインストール

プロジェクトディレクトリで以下のコマンドを実行：

```bash
# 仮想環境を作成
python3 -m venv venv

# 仮想環境をアクティベート
source venv/bin/activate

# 必要なライブラリをインストール
pip install -r requirements.txt
```

## 🚀 使用方法

### アプリの起動

#### 方法1: .commandファイル（最も推奨）
1. Finderで `写真文字読み取りアプリ.command` をダブルクリック
2. ターミナルが開いてアプリが起動します

#### 方法2: カスタムアプリバンドル
1. Finderで `写真文字読み取りアプリを起動.app` をダブルクリック

#### 方法3: シェルスクリプト
```bash
./launch_ocr_app.sh
```

#### 方法4: 直接実行（開発者向け）
```bash
source venv/bin/activate
python ocr_app.py
```

### 基本的な使い方

1. **画像を選択**
   - 「📁 画像を選択」ボタンをクリック
   - 読み取りたい文字が写っている画像ファイルを選択

2. **文字を読み取る**
   - **印刷文字の場合**: 「🔍 文字を読み取る」ボタンをクリック
   - **手書き文字の場合**: 「✍️ 手書き文字を読み取る」ボタンをクリック
   - 自動的に画像から文字が読み取られます

3. **テキストを保存**
   - 読み取り結果を確認・編集
   - 「💾 テキストを保存」ボタンをクリック
   - 保存先とファイル名を指定してテキストファイルを保存

## ✍️ 手書き文字認識について

新しく追加された手書き文字認識機能では、以下の特徴があります：

- **最適化された設定**: 手書き文字専用のOCR設定を使用
- **文字種対応**: ひらがな、カタカナ、漢字、英数字に対応
- **認識精度**: 印刷文字とは異なる最適化により、手書き文字の認識精度を向上

### 手書き文字認識のコツ

- **文字の大きさ**: できるだけ大きく、はっきりと書かれた文字
- **背景**: 白い紙に黒いペンで書かれた文字が最適
- **文字間隔**: 文字同士が重ならないよう適度な間隔を保つ
- **画像品質**: 高解像度で影や歪みの少ない画像を使用

## 📝 対応ファイル形式

- **入力画像**: PNG、JPEG、GIF、BMP、TIFF
- **出力テキスト**: TXT（UTF-8エンコーディング）

## 💡 使用のコツ

- **画像の品質**: 高解像度で文字がはっきり写っている画像ほど認識精度が向上します
- **文字の向き**: 文字が正しい向きで写っている画像を使用してください
- **背景**: 文字と背景のコントラストがはっきりしている画像が最適です
- **言語**: 日本語と英語の混在した文書も認識できます

## 🔧 トラブルシューティング

### アプリが起動しない場合

1. **最も確実な方法**: `写真文字読み取りアプリ.command` をダブルクリック
2. **権限エラー**: ターミナルで `chmod +x 写真文字読み取りアプリ.command` を実行
3. **仮想環境エラー**: `source venv/bin/activate` でアクティベートしてから `python ocr_app.py` を実行

### Tesseractが見つからないエラー

```
TesseractNotFoundError: tesseract is not installed
```

このエラーが出た場合は、Tesseractが正しくインストールされていません。上記のインストール手順を再度実行してください。

### 日本語が認識されない

日本語の認識精度を向上させるには：
1. 日本語言語パックが正しくインストールされているか確認
2. 画像の品質を向上させる
3. 文字のサイズが十分大きいか確認

### py2appアプリが起動しない

py2appで作成された `.app` ファイルがCarbonフレームワークエラーで起動しない場合は、代替手段を使用してください：
- `写真文字読み取りアプリ.command` （推奨）
- `写真文字読み取りアプリを起動.app`
- `launch_ocr_app.sh`
