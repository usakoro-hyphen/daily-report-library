# � 日報図書館

テキストファイルとワードライブラリを管理するWebアプリケーション。

## 🌟 機能

### � テキストファイルライブラリ
- テキストファイル（.txt）の読み込み
- ドラッグ&ドロップ対応
- ライブラリへの保存と管理
- ファイル名検索機能
- パスワード保護付き削除機能

### � ワードライブラリ
- 自動用語抽出（…や＝で区切られた単語）
- 用語検索機能
- 詳細説明表示
- ランダム表示（最大3件）
- パスワード保護付き削除機能

### 🛡️ セキュリティ
- パスワード保護機能付き削除機能
- 二段階認証（パスワード + 確認ダイアログ）
- パスワードは非表示入力で安全に管理

### 🎨 デザイン
- モダンなUI
- レスポンシブ対応
- グラデーションデザイン
- アニメーション効果

## 🚀 使用方法

1. テキストファイルを読み込む
2. 「ライブラリに保存」をクリック
3. 抽出された用語がワードライブラリに自動保存
4. 用語をクリックして詳細を確認

## 🔐 セキュリティについて

すべての削除機能はパスワードで保護されています：
- ワードライブラリの削除
- テキストファイルライブラリの削除
- すべてのデータの削除

パスワードは非表示入力で安全に管理されます。

## 🔧 機能詳細

### テキストファイル読み込み
- .txtファイル形式に対応
- ドラッグ&ドロップまたはファイル選択
- 自動テキスト整形と段落分け

### 用語抽出
- 「…」や「＝」で区切られた単語を自動認識
- 太字表示で用語を強調
- ライブラリ保存時に自動抽出

### 検索機能
- テキストファイル：ファイル名検索
- ワードライブラリ：用語検索
- リアルタイム検索結果表示
